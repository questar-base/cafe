01 // Concept

みんなで創る、育つ店。オタク＝何かに情熱を注げる人

クエスターベースカフェは、岐阜県多治見市のJR多治見駅南口から徒歩2分。青い看板が目印の、オタクが集う会員制カフェです。

ここはただの飲食店ではありません。会員（クエスター）と一緒にお店を作っていく「会員参加型店舗」。会員の声や活動がお店を変えていく、今までにないワクワクするお店を目指しています。

合言葉は「オタクとは、何かに情熱を注げる人」。分野は問いません。ボードゲーム、ドール、アニメ、コスプレ、カード、占い——好きを持ち寄る人が、ここでは主役です。

  • ▶ 会員の意見でメニューや設備がレベルアップする「育成型店舗」
  • ▶ 多治見をオタクの聖地に。地域活性化・町おこしにも参戦
  • ▶ 好きなことをビジネスの第一歩にする「間借り起業」を応援
「オタク」とは、何かに情熱を注げる人のこと。
その情熱を持ち寄って、みんなで育てる多治見の秘密基地です。

04 // Activities

ここで遊べること、はじまること遊ぶ・推す・社会貢献、ぜんぶ基地の仕事

// Board Game

ボードゲームカフェ

約200種のボードゲームを常備。初心者も常連も、その日の気分で1本どうぞ。

// Doll

ドール集会

ドールオタクの聖地。お迎え自慢も、撮影会も、交流も。あなたの推しを見せてください。

// Tarot

タロット占い

曜日によって占い師が営業。気になる運勢も、推し活の相談も、ここで占ってみる。

// Social Quest

コスプレ街清掃「転サブ」

コスプレで多治見の街をきれいにする社会貢献活動。好きな格好で、地域に貢献。

// Marche

駅北庁舎マルシェ

浅井団長が企画運営。多治見市役所 駅北庁舎2階でのマルシェなど、町おこしを推進。

// Culture Mix

ビリヤード・ダーツ・ギター・トレカ

遊具も推し活も盛りだくさん。多治見が舞台の「やくならマグカップも」巡礼マップも展示。

05 // Share-kari

好きを、ビジネスの第一歩に。間借りシステムで、きみも店長

クエスターベースカフェのもうひとつの顔が、間借りシステムです。

曜日によって、ボードゲームカフェやタロット占い屋など、さまざまなお店が営業。固定費の大きい独立ではなく、まずは間借りで「自分の店」を開いてみる。オタクのビジネスの第一歩を応援します。

  • ▶ 曜日・時間帯を選んで、自分の業態をテストできる
  • ▶ 多治見駅前・徒歩2分という好立地でチャレンジ
  • ▶ クエスター（会員）が最初のお客様になってくれる
